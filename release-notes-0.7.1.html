PCAN-Explorer10 0.7.1发布于 2026-09-18

本版本聚焦运行状态可观察性、弹窗一致性和状态栏布局，并完成 Rust 1.95 发布检查适配。

更新内容

  • 重构运行诊断面板，实时展示界面、队列、硬件、记录与时间戳质量指标。
  • 统一诊断弹窗和升级提示的圆角、卡片、间距及按钮布局。
  • 将“运行诊断”固定到状态栏最右侧并保持垂直居中。
  • 缩短弹窗淡入和缩放过渡，修正强调竖条与圆角边框越界。
  • 适配 Rust 1.95 的发布静态检查规则。

发布验证

  • Git 空白检查、Rust 格式化通过。
  • CAN、Serial、Modbus 三套 Slint UI 语法检查通过。
  • UI 渲染矩阵、工作区测试、零警告 Clippy 审计通过。
  • 发布报告记录的源码提交：5e8bec2fcc94a36c694b4882ba8687a4e8440814。
