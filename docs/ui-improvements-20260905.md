# UI 修复与验证（2026-09-05）

## 六项改动

1. DBC 发送、信号变化：单击只选中，双击添加；新增“添加选中报文”按钮并同步帮助。可折叠 DBC 库。
2. 响应式：发送窗口支持 820px，原始数据和名称输入自适应；信号信息改为可滚动两列表单，避免原始值越界。DBC/变化任务区域提供横向滚动，保持各列可达。帮助正文按可用宽度换行。Modbus/串口窄窗口自动折叠连接参数，并保留按钮重新打开。
3. 状态栏：原长串诊断指标移入“运行诊断”详情；状态栏保留连接/测量、计数、帧速率和负载，异常时按钮提示“异常 / 详情”。详情可放大/缩小，支持 Escape 和关闭按钮。
4. 筛选：显示控制与筛选分为两排；增加语法说明、待应用/已生效状态、非法 ID/Data 校验。方向与其他条件统一点击应用生效；非法输入不会覆盖旧条件。
5. 更新：小提示高度 180px，完整内容在独立覆盖层中阅读，可放大、自动换行和滚动。不是新建原生窗口；详情尺寸跟随主窗口。
6. Trace：显式提供 300/750/1500 行实时显示窗口，默认 300；采集缓存和记录不受影响。关闭自动滚动后冻结当前表格以便查看，显式筛选、排序和清空仍生效，恢复自动滚动显示最新数据。
